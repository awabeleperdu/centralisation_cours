À RETENIR

1. Introduction : compilation et premier programme

Contrairement à Python, le C++ est un langage compilé : le code source (.cpp) est transformé par un compilateur (g++, clang++, MSVC) en un exécutable binaire avant de pouvoir être lancé. Cette étape supplémentaire permet des vérifications de type strictes et des programmes très performants, au prix d'un cycle développement/test un peu plus long.

// hello.cpp
#include <iostream>

int main() {
    std::cout << "Bonjour BTS CIEL !" << std::endl;
    return 0;
}

Compilation puis exécution en ligne de commande :

g++ hello.cpp -o hello
./hello
ÉlémentRôle
#include <iostream>Importe la bibliothèque d'entrées/sorties (équivalent d'un import Python)
int main()Point d'entrée obligatoire du programme
std::cout <<Affiche sur la sortie standard (comme print())
return 0;Indique au système d'exploitation que le programme s'est terminé sans erreur
À RETENIR
Chaque instruction se termine par un point-virgule ;. Les blocs de code sont délimités par des accolades { }, et non par l'indentation comme en Python (même si une bonne indentation reste indispensable pour la lisibilité).

2. Types de données, variables et opérateurs

Le C++ est typé statiquement : le type d'une variable est fixé à sa déclaration et ne change jamais, contrairement à Python.

TypeContenuExemple
intEntierint age = 17;
float / doubleNombre à virgule (double = plus grande précision)double pi = 3.14159;
charUn seul caractèrechar lettre = 'A';
boolVrai/Faux (true/false)bool actif = true;
std::stringChaîne de caractères (bibliothèque standard)std::string nom = "Amir";

Opérateurs courants : arithmétiques + - * / %, comparaison == != < > <= >=, logiques && || !, affectation composée += -= *= /=, incrémentation ++ / décrémentation --.

ATTENTION — division entière
7 / 2 entre deux int vaut 3 (division entière, la partie décimale est tronquée), pas 3.5. Pour obtenir un résultat décimal, il faut qu'au moins un des deux opérandes soit un float/double : 7.0 / 2 vaut bien 3.5.

Le mot-clé const déclare une variable dont la valeur ne pourra plus changer après initialisation : const double TVA = 0.20;.

3. Structures de contrôle

// Condition
if (note >= 10) {
    std::cout << "Admis";
} else if (note >= 8) {
    std::cout << "Rattrapage";
} else {
    std::cout << "Recalé";
}

// Boucle for : compteur classique
for (int i = 0; i < 10; i++) {
    std::cout << i << " ";
}

// Boucle while : condition vérifiée avant chaque tour
int n = 5;
while (n > 0) {
    std::cout << n << " ";
    n--;
}

// Boucle do-while : le corps s'exécute au moins une fois
int saisie;
do {
    std::cout << "Entrez un nombre positif : ";
    std::cin >> saisie;
} while (saisie < 0);

// switch : équivalent d'une longue chaîne de if/else if
switch (jour) {
    case 1: std::cout << "Lundi"; break;
    case 2: std::cout << "Mardi"; break;
    default: std::cout << "Autre jour";
}
ATTENTION — le break dans un switch
Oublier break; à la fin d'un case provoque un fall-through : l'exécution continue dans le case suivant, même si sa condition n'est pas remplie. C'est une source d'erreur très classique.

4. Fonctions

// Déclaration : type de retour, nom, paramètres typés
int addition(int a, int b) {
    return a + b;
}

// Passage par valeur : la fonction reçoit une COPIE
void incrementerValeur(int x) {
    x = x + 1;  // n'affecte pas la variable d'origine
}

// Passage par référence : la fonction modifie la variable d'origine
void incrementerReference(int &x) {
    x = x + 1;  // modifie réellement la variable appelante
}

// Surcharge de fonction : même nom, signatures différentes
int carre(int x) { return x * x; }
double carre(double x) { return x * x; }
À RETENIR
Par défaut, les paramètres sont passés par valeur (copie). Pour qu'une fonction modifie réellement une variable de l'appelant, il faut un paramètre par référence (&) ou par pointeur (*, voir section 6).

5. Tableaux et chaînes de caractères

// Tableau statique de taille fixe
int notes[5] = {12, 15, 8, 17, 10};
std::cout << notes[0];  // -> 12 (indexation à partir de 0)

// Parcours d'un tableau
for (int i = 0; i < 5; i++) {
    std::cout << notes[i] << " ";
}

// Tableau à deux dimensions
int grille[2][3] = { {1,2,3}, {4,5,6} };

// Chaîne de caractères moderne (recommandée)
std::string nom = "Amir";
nom += " Eddahmani";           // concaténation
std::cout << nom.length();    // longueur de la chaîne
ATTENTION — dépassement de tableau
Contrairement à Python, le C++ ne vérifie pas automatiquement les indices d'un tableau statique. Accéder à notes[10] sur un tableau de taille 5 ne provoque pas forcément d'erreur immédiate visible, mais lit une zone mémoire invalide — un comportement indéfini (undefined behavior), source de bugs difficiles à diagnostiquer.

6. Pointeurs et références

Un pointeur est une variable qui stocke une adresse mémoire plutôt qu'une valeur directe. C'est la notion la plus caractéristique du C/C++, et celle qui n'a pas d'équivalent direct en Python.

OpérateurNomEffet
&Adresse deRécupère l'adresse mémoire d'une variable
*DéréférencementAccède à la valeur pointée par une adresse
newAllocation dynamiqueRéserve de la mémoire sur le "tas" (heap)
deleteLibérationLibère une mémoire allouée avec new
int a = 10;
int *p = &a;         // p contient l'adresse de a
std::cout << *p;    // -> 10 (déréférencement : valeur pointée)
*p = 20;             // modifie a via le pointeur : a vaut maintenant 20

// Allocation dynamique
int *q = new int(42);  // réserve un int sur le tas, initialisé à 42
delete q;               // libère la mémoire — obligatoire !

🧠 Visualiseur mémoire — comprendre les pointeurs pas à pas

ATTENTION — pointeur non initialisé
Un pointeur déclaré sans être initialisé (int *p;) contient une adresse aléatoire. Le déréférencer avant de lui affecter une adresse valide (*p = 5;) est un comportement indéfini pouvant planter le programme. Initialisez toujours un pointeur, au besoin avec nullptr.

Une référence (& dans une déclaration de variable, section 4) est un "alias" d'une variable existante : contrairement à un pointeur, elle ne peut pas être nullptr et ne peut pas être réaffectée à une autre variable après sa création.

7. Structures et énumérations

// Une structure regroupe plusieurs champs sous un même type
struct Etudiant {
    std::string nom;
    int age;
    double moyenne;
};

Etudiant e1;
e1.nom = "Amir";
e1.age = 17;
e1.moyenne = 15.5;

// Tableau de structures
Etudiant classe[30];
classe[0].nom = "Amir";

// Énumération : ensemble de constantes nommées
enum Jour { LUNDI, MARDI, MERCREDI, JEUDI, VENDREDI, SAMEDI, DIMANCHE };
Jour aujourdhui = MERCREDI;
À RETENIR
Une struct est très proche d'une classe (section 8) : la seule différence par défaut en C++ est que les champs d'une struct sont publics par défaut, alors que ceux d'une class sont privés par défaut.

8. Programmation orientée objet : les classes

class Rectangle {
private:
    double largeur;
    double hauteur;

public:
    // Constructeur : initialise l'objet à sa création
    Rectangle(double l, double h) {
        largeur = l;
        hauteur = h;
    }

    // Méthodes publiques
    double aire() {
        return largeur * hauteur;
    }
    double perimetre() {
        return 2 * (largeur + hauteur);
    }
};

// Utilisation
Rectangle r(5.0, 3.0);
std::cout << r.aire();  // -> 15
Mot-cléEffet
privateAccessible uniquement depuis l'intérieur de la classe (encapsulation)
publicAccessible depuis l'extérieur de la classe
protectedAccessible depuis la classe et ses classes filles (voir héritage)
À RETENIR
L'encapsulation consiste à rendre les données internes d'un objet (private) inaccessibles directement de l'extérieur, et à ne les manipuler qu'à travers des méthodes publiques contrôlées. Cela protège la cohérence de l'objet (ex : empêcher une largeur négative).

9. Héritage et polymorphisme

class Animal {
protected:
    std::string nom;
public:
    Animal(std::string n) : nom(n) {}
    virtual void crier() {
        std::cout << nom << " fait un bruit." << std::endl;
    }
};

class Chien : public Animal {
public:
    Chien(std::string n) : Animal(n) {}
    void crier() override {
        std::cout << nom << " aboie !" << std::endl;
    }
};

// Polymorphisme : un pointeur d'Animal peut désigner un Chien
Animal* a = new Chien("Rex");
a->crier();  // -> "Rex aboie !" (la version de Chien est appelée)
delete a;
Mot-cléRôle
: public AnimalChien hérite de tous les membres publics/protégés d'Animal
virtualAutorise une classe fille à redéfinir la méthode (liaison dynamique)
overrideIndique explicitement qu'on redéfinit une méthode virtuelle (sécurité à la compilation)
ATTENTION
Sans le mot-clé virtual sur crier() dans Animal, l'appel a->crier() exécuterait la version d'Animal et non celle de Chien, même si a pointe réellement vers un objet Chien : c'est la différence entre liaison statique et liaison dynamique.

10. La bibliothèque standard : std::vector et templates + hors programme

std::vector est un tableau dynamique (taille modifiable à l'exécution) de la bibliothèque standard (STL), bien plus sûr et pratique qu'un tableau C classique :

#include <vector>

std::vector<int> notes = {12, 15, 8};
notes.push_back(17);        // ajoute un élément à la fin
std::cout << notes.size();  // -> 4
for (int n : notes) {        // boucle "for each", comme en Python
    std::cout << n << " ";
}

Les templates permettent d'écrire une fonction ou une classe générique, indépendante du type manipulé :

template <typename T>
T maximum(T a, T b) {
    return (a > b) ? a : b;
}
maximum(3, 7);       // -> 7 (avec des int)
maximum(2.5, 1.1);   // -> 2.5 (avec des double)

11. Gestion des exceptions + hors programme

Le mécanisme try / catch / throw permet de gérer proprement les erreurs à l'exécution plutôt que de laisser le programme planter brutalement :

double diviser(double a, double b) {
    if (b == 0) {
        throw std::runtime_error("Division par zéro");
    }
    return a / b;
}

try {
    double r = diviser(10, 0);
} catch (const std::runtime_error &e) {
    std::cout << "Erreur : " << e.what() << std::endl;
}

12. RAII et pointeurs intelligents + hors programme

Oublier un delete après un new provoque une fuite mémoire. Le C++ moderne recommande d'éviter new/delete manuels et d'utiliser des pointeurs intelligents, qui libèrent automatiquement la mémoire quand ils sortent de portée (principe RAII — Resource Acquisition Is Initialization) :

#include <memory>

std::unique_ptr<Rectangle> r = std::make_unique<Rectangle>(5.0, 3.0);
std::cout << r->aire();
// pas besoin de delete : la mémoire est libérée automatiquement
// quand "r" sort de portée, même en cas d'exception
À RETENIR
std::unique_ptr = un seul propriétaire de la ressource. std::shared_ptr = plusieurs propriétaires, avec un compteur de références qui libère la mémoire quand il atteint zéro. C'est la norme en C++ moderne (C++11 et plus) pour éviter les fuites mémoire.

13. Compilation multi-fichiers : .h / .cpp + hors programme

Un projet réel sépare la déclaration (fichier d'en-tête .h/.hpp) de l'implémentation (fichier .cpp), pour pouvoir compiler chaque fichier indépendamment et les réutiliser dans plusieurs projets :

// rectangle.h — déclaration
class Rectangle {
public:
    Rectangle(double l, double h);
    double aire();
private:
    double largeur, hauteur;
};

// rectangle.cpp — implémentation
#include "rectangle.h"
Rectangle::Rectangle(double l, double h) : largeur(l), hauteur(h) {}
double Rectangle::aire() { return largeur * hauteur; }

// main.cpp — utilisation
#include "rectangle.h"
int main() {
    Rectangle r(5, 3);
    return 0;
}

Le symbole :: (opérateur de résolution de portée) indique à quelle classe appartient la méthode définie dans le .cpp.
